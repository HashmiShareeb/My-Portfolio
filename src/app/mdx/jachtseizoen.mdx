


This project is inspired by the Dutch TV show **Jachtseizoen**. The goal was to design and build a **real-time multiplayer game** where players use navigation and live location updates to track down other players within a defined radius. Player locations are updated every **10 seconds**. When the **Jager** comes within range of the **Boef**, the *“gevonden”* button becomes active, allowing the Jager to catch the Boef and end the game.

## Gameplay & Features

- Players can **create or join a game session**
- Each game generates a **unique lobby code** (Kahoot-inspired)
- Players **join the lobby** using this code
- Roles are randomly assigned:
  - **Jager** (Hunter)
  - **Boef** (Fugitive)
- The game ends when the Boef is caught or when the host leaves the session

##  Backend & Database setup
The backend of the application used **Azure Cosmos DB**, a NoSQL database well-suited for real-time and scalable data storage. While I was not the primary backend developer, I proposed the use of Cosmos DB and actively collaborated with the backend team to ensure seamless integration with the frontend.

## Challanges & Conclusion
The part of this project that was hardest to complete was definitely the **real-time multiplayer functionality**. To coordinate player locations in real time and to ensure that the Jager’s tracking screen updates dynamically, while ensuring that all of this happens at regular intervals with storage in the back end, was definitely challenging.

These challenges have pushed me to think critically about performance issues of consistency and experience in real-time environments. Issues of consistency and small performance differences had a real-world effect on the gameplay experience and are what make consistency and clarity in UI so important.

In conclusion, the project helped me improve my concepts related to real-time systems, the interaction between the frontend and backend, and collaborative problem-solving. The project showcases how I can work with complex technological systems in addition to emphasizing user interface and system integrity.
